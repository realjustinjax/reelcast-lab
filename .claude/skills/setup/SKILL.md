# Set up ReelCast Lab

Read `SETUP.md` in the root of this folder and follow it from the top.

- Run `python3 scripts/setup_env.py check` first, and skip every step it reports as done.
- One question at a time. Wait for each answer.
- Run the commands yourself. Before installing software or starting the background job, say what will happen and wait for a yes.
- Never ask for a password, key or token.
- Finish with the practice run, then their first real video. Do not call setup done before the practice run has produced five versions.
